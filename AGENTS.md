# Lingvaden: инструкции для разработки

Сначала прочитай `HANDOVER.md` и `FIRST_PROMPT.md`. Доступы находятся в `handover-private/credentials.json`; не выводи пароли и секрет приложения в чат и логи.

Изменяй исходники, затем запускай `python3 build.py`. `output/` — результат сборки. Изображения учебника уже находятся в `output/assets/img/`: сохраняй эту папку при сборке и переносе.

Текущий сайт: `lingvaden.ru`; публикация: `python3 tools/deploy_ftp.py` или `./deploy.sh`. Эти команды работают с новым FTP. `--check` проверяет FTP без изменений, `--dry-run` собирает сайт без публикации. Данные подключения не должны попадать в `output/` или `www`.

Рабочая база `u551141_database` содержит реальные данные. Не выполнять TRUNCATE, DROP, DELETE FROM, ALTER … DROP и не импортировать дамп поверх рабочей базы. Изменения схемы — добавляющие в `server/api/_lib.php`. Тестировать через отдельный кабинет с кодом `000000` и пометкой TEST. Перед изменением базы сделать её актуальную резервную копию. Публикация файлов сама по себе базу не экспортирует и не меняет.

Не использовать старый сайт `english.reknow.ru` и локальные SSH-ключи прежнего владельца для новой разработки. Доступ к панели хостинга, DNS и сертификатам в комплект не предоставлялся; проверяй фактическое состояние, не считай прошлый статус текущим.

Если работа идёт в облачной среде (claude.ai → Code) без `handover-private/`, сайт публикуется через GitHub Actions при изменении ветки `main` (секрет `LINGVADEN_FTP`); см. `README.md`. Локальный FTP-деплой в облаке не запускать.
