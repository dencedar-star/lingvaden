# Передача проекта Lingvaden

Пакет передачи подготовлен 20 октября 2026 года. Состояние DNS и веб-сервера ниже зафиксировано при переносе 19 октября; перепроверьте его при разворачивании.

## Доступы

В папке `handover-private/` находятся:

- `credentials.json` — FTP, MySQL, адреса, пути на сервере и проверочный код.
- `english_config.php` — конфигурация новой базы и секрет приложения, соответствующие загруженному сайту.
- `database.sql` — свежий экспорт всех 18 таблиц новой базы от 20 октября 2026 года, включая тестового преподавателя. Не импортировать поверх рабочей базы.

Эта папка содержит действующие пароли, исключена из Git и не входит в сборку сайта. Передавайте её новому ответственному отдельно либо вместе с полной копией проекта по защищённому каналу. Не загружайте её в `www`. При передаче через Git папку нужно передать отдельно. После передачи обновите пароли и соответствующие настройки приложения.

## Структура и сборка

- `content/` — учебные материалы.
- `site/` — JavaScript, CSS и статические файлы.
- `server/api/` — PHP API и схема MySQL.
- `build.py`, `lib.py`, `platform_pages.py` — генератор HTML.
- `media/`, `sources/` — медиа и исходные материалы.
- `output/` — результат сборки, не место для ручных изменений.

Сборка: `python3 build.py`. Для сборки и FTP-публикации достаточно Python 3.10+ со стандартной библиотекой, установка pip-пакетов не нужна. На веб-хостинге требуются PHP с PDO MySQL и mbstring, MySQL и веб-сервер с обработкой правил `.htaccess`. Для подготовки медиа и изображений нужны дополнительные зависимости скриптов `tools/`; готовые файлы уже есть в проекте.

## Публикация на новом хостинге

1. Сделайте резервную копию файлов и экспорт текущей MySQL-базы.
2. Выполните сборку и загрузите содержимое `output/`, включая `.htaccess`, в `/lingvaden.ru/www` по FTP.
3. Файл `handover-private/english_config.php` должен находиться на сервере в `/lingvaden.ru/english_config.php`, вне `www`. Сохраните ограниченные права доступа к нему.
4. Проверьте вход и кабинеты. Код `000000` назначен отдельному тестовому преподавателю с пометкой TEST.

`deploy.sh` теперь публикует на новый FTP Lingvaden через `tools/deploy_ftp.py`.

- `python3 tools/deploy_ftp.py --dry-run` — сборка без подключения и публикации.
- `python3 tools/deploy_ftp.py --check` — проверка FTP и папки www без изменений.
- `python3 tools/deploy_ftp.py` — сборка и публикация; предыдущие версии заменяемых файлов сохраняются в `handover-private/backups/`. При первой публикации проверяются все файлы, поэтому она может занять время. Последующие публикации используют манифест SHA-256 вне www.
- `python3 tools/deploy_ftp.py --configure` — дополнительно загрузить конфигурацию вне www, сохранив предыдущую версию локально.

Скрипт не удаляет лишние файлы сервера и не меняет MySQL. Перед изменениями базы нужен отдельный свежий экспорт. Старый SSH-скрипт заменён; ключи прежнего владельца не требуются для FTP-публикации.

## Работа с данными

В базе есть реальные данные. Не удаляйте и не очищайте таблицы при настройке. Следуйте правилам `CLAUDE.md`; при изменениях схемы учитывайте автоматические миграции в `server/api/_lib.php`. Не используйте исходную базу старого сайта для тестирования.

## Передача через GitHub (29 октября 2026)

Проект размещён в приватном репозитории GitHub. В репозиторий не входят `handover-private/`, `transfer/` и результат сборки `output/` (кроме `output/assets/img/`). Публикация на FTP автоматизирована через GitHub Actions: секрет репозитория `LINGVADEN_FTP` содержит JSON вида `{"ftp": {...}}` с теми же полями, что раздел `ftp` в `credentials.json`. Инструкция для нового владельца — `README.md`.
