# Lingvaden — правила проекта

Актуальные инструкции для агента находятся в `AGENTS.md`, передача проекта описана в `HANDOVER.md`.

Рабочая база: `u551141_database`. Не выполнять TRUNCATE, DROP, DELETE FROM, ALTER … DROP. Не импортировать дамп поверх рабочей базы. Изменения схемы — только добавляющие. Тестовый кабинет: код `000000`, пометка TEST.

Публикация: `python3 tools/deploy_ftp.py` или `./deploy.sh` — новый FTP Lingvaden. Конфигурация хранится вне www. Скрипт сохраняет локальную резервную копию заменяемых файлов; автоматическая резервная копия MySQL на новом хостинге не настроена и не подтверждена.

Старые правила о SSH, базе `u526328_english` и резервных копиях на english.reknow.ru относились к исходному сайту и не описывают новый хостинг.

## Работа через Claude Code в облаке (claude.ai → Code)

С проектом работает человек без ИТ-опыта. Объясняй простыми словами, без терминов; не проси выполнять команды в терминале и ничего устанавливать.

- В облаке нет `handover-private/` и доступа к FTP и MySQL — это нормально. Не запускай `deploy.sh` и `tools/deploy_ftp.py`, не ищи и не спрашивай пароли.
- Порядок работы: прочитай задачу → правь исходники (`content/`, `site/`, `lib.py`, `platform_pages.py`, `server/api/`), а не `output/` → проверь сборку `python3 -B build.py`. Для сборки нужны `pdftotext` (пакет poppler-utils) и Pillow: если их нет, установи (`pip install pillow`, `apt-get install -y poppler-utils`, при необходимости через sudo). Если установить не удалось, сборку проверит GitHub.
- Публикация на сайт происходит автоматически (GitHub Actions) после попадания изменений в ветку `main`, обычно за 3–10 минут.
- Когда правка готова: закоммить её и отправь в `main`, если пользователь просит опубликовать сразу. Иначе создай pull request и дай ссылку с короткой инструкцией: «Откройте ссылку → дождитесь зелёной галочки → нажмите Merge pull request → Confirm merge».
- После правки коротко перечисли, что изменилось и на какой странице сайта это видно (адрес на lingvaden.ru). Напомни обновить страницу с очисткой кеша (Ctrl+F5 / Cmd+Shift+R).
- Если пользователь пишет, что публикация упала (красный крестик), попроси прислать текст ошибки или скриншот со страницы Actions и исправь причину.
- Откат: по просьбе «верни как было» сделай `git revert` нужного коммита и отправь в `main`.
- Не меняй структуру базы данных и не удаляй данные без явной просьбы владельца; при любых изменениях в `server/api/` предупреждай пользователя, что это затрагивает кабинеты учеников и преподавателей.
