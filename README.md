# Lingvaden — lingvaden.ru

Интерактивный курс английского (Outcomes Intermediate): статический сайт, PHP API и MySQL на хостинге Masterhost.

## Как вносить изменения (без навыков программирования)

1. Откройте **claude.ai → Code**, выберите этот репозиторий.
2. Опишите задачу обычными словами, например: «Поменяй текст на главной странице на …» или «Добавь в модуль 3 упражнение …».
3. Claude внесёт правки, проверит сборку и предложит изменения (pull request).
4. Откройте pull request на GitHub и нажмите **Merge pull request**. Можно также попросить Claude: «закоммить сразу в main».
5. Через 2–5 минут сайт обновится сам. Ход публикации виден на вкладке **Actions** репозитория (зелёная галочка — готово, красный крестик — ошибка; ссылку на ошибку можно отдать Claude).

Публикация запускается при каждом изменении ветки `main`. Вручную её можно запустить так: Actions → «Публикация на lingvaden.ru» → Run workflow (режим `check` только проверяет FTP).

## Разовая настройка (делается один раз)

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**

- Name: `LINGVADEN_FTP`
- Secret: содержимое файла `github-secret-LINGVADEN_FTP.json` из папки с доступами (`handover-private/`), передаётся отдельно от репозитория.

## Важно

- Пароли не хранятся в репозитории и не должны в него попадать.
- В базе реальные данные учеников: никаких удалений и очисток таблиц. Подробности — `CLAUDE.md`, `AGENTS.md`, `HANDOVER.md`.
- Тестовый кабинет: код `000000`.
